# Shopping Cart App - Expo SDK / React Native

This folder is a standalone, ready-to-run React Native project configured for **Practical 5: Product List with Add to Cart**.

## What's Included

- **`App.tsx`**: Complete React Native implementation with DummyJSON API fetching, cart state management, quantity controls, order summary, and safe area handling.
- **`start-expo.bat`**: Double-click launcher to start the Expo dev server immediately.
- **`package.json` & `app.json`**: Expo configuration with web and mobile support.

## How to Run

### Method 1: Double-click Launcher
Double-click `start-expo.bat` (either in the project root or in `expo-react-native/`).

### Method 2: Command Line
```bash
cd expo-react-native
npm install
npx expo start
```

- **Mobile**: Scan the displayed QR code using the **Expo Go** app on your phone (Android or iOS).
- **Web**: Press `w` in the terminal to view and test directly in your browser.
